=== WebAssembly Interface Types Demo ===

1. Working with Record types (Person struct)
--------------------------------------------
Created Person record at offset: 0
  name: Alice
  age: 30

2. Working with Option types (nullable email)
---------------------------------------------
  Alice has email: true
  Bob has email: false

3. Working with List types (list<person>)
-----------------------------------------
  List length: 2
  [0] Alice (age 30)
  [1] Bob (age 15)

4. Working with Variant types (Result enum)
-------------------------------------------
  Result tag: 0 (0=Success, 1=NotFound, 2=InvalidInput)
  Error result tag: 2 (InvalidInput)

=== Interface Types Demonstrated ===
✓ Records (struct-like): Person with name, age, email
✓ Strings: UTF-8 strings with length prefix
✓ Options: Nullable email field
✓ Lists: Dynamic array of Person records
✓ Variants: Result enum with Success/NotFound/InvalidInput

All interface type patterns work in plain WAT!
